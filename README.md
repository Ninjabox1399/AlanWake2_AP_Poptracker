# Alan Wake 2 Archipelago Poptracker
A poptracker pack for my manual archipelago randomiser for Alan Wake 2, found here: https://github.com/Ninjabox1399/AlanWake2_Archipelago

This tracker contains two versions, a compact and larger version of the map. I tested the compact one on my laptop screen (16:10), whereas the larger one fits on my monitor (16:9).

Features:
- Full in-game maps with (mostly) accurate checks placed on them
- Full item tracker including:
  - Weapons
  - Saga Key Items
  - Alan Key Items
  - DLC Key Items
  - Saga Charms
  - Nursery Rhyme Dolls
  - Alan doing a a funny little dance as you collect more Progressive Verse fragments to goal
- Archipelago check sending from the map
- Annotated maps with all the codes and puzzle solutions
- Broadcast view to easily see which items you have received

Caution - Unlike the manual archipelago client, the poptracker does not have protections in place for sending out-of-logic checks, so be careful which locations you send!
